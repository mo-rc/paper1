## P14 checker: domain, section model and checks

- **Decision (project lead) — common fabricated domain:** all optimizers, SAC, branching Q and hybrids propose the same increment-grid designs defined above. Map off-grid proposals to the nearest in-bound grid point independently per variable; exact half-increment ties round down. Then apply geometric constraints. Invalid geometry is deterministically rejected and counted as an infeasible checker evaluation; it cannot be repaired into a different geometry. Cache by canonical `(h,b,tw,tf,context)`; only the first evaluation costs one checker call, and duplicate requests return the stored result at zero additional checker calls. Every unique valid or invalid canonical geometry consumes one call. **READ** — `docs/spec.md:106-115,142,152,256`; `docs/patch_plan.md:45,49-51`.
- **Decision (project lead) — SLSQP and accounting:** first optimize the continuous relaxation using continuous mass and a continuous structural constraint function that is the same code as the grid checker's equations, not a second implementation. Do not project inside SLSQP's objective or use ordinary finite differences on a projected piecewise-constant function. Project the final point, evaluate it with the checker, then search grid neighbours within one increment per coordinate; select the lightest checked feasible design and stop when no neighbour improves it or the per-context unique-grid-checker-call cap is reached. Count each unique canonical design sent to the checker once; cache hits cost zero. Describe the result as a local grid search, not an optimality certificate. Report separately (i) full checker calls, (ii) continuous structural evaluations, (iii) cache hits, (iv) total call-equivalents (i + ii), and (v) wall-clock. Primary S5 remains registered checker calls per verified design; supplementary call-equivalents do not replace it. The 1,000 cap applies only to unique grid-checker calls. The continuous phase has a fixed maximum iteration count, value **TO BE SET at pre-P16 freeze** and checked during P16 profiling; continuous evaluations are never unlimited. **READ** — `docs/spec.md:152,252,256`; `docs/patch_plan.md:45,49`.
- **Decision (project lead) — fabricated-section properties:** for clear web depth `hw=h-2tf`, use `A=2btf+hw*tw`, centroid at mid-depth, and strong-axis `Iy=2[btf^3/12+btf((h-tf)/2)^2]+tw*hw^3/12`; weak-axis `Iz=2tf*b^3/12+hw*tw^3/12`. Calculate `Wel,y=Iy/(h/2)` and plastic modulus by first moment of yielded plate areas about the plastic neutral axis. State exact formulas, units, rounding, and tolerances in P14. These sharp-corner formulas omit weld metal, radii, residual stress and plate imperfections; these remain unverified. **READ** — `docs/patch_plan.md:45,47`; `docs/project_review.md:108-112`.
- **Decision (project lead) — class and resistance model:** classify flange outstands and web under EN 1993-1-1 Table 5.2 using clear widths, S355 thickness-dependent `fy`, and `epsilon`; support classification through Class 4, but conservatively reject Class 4 as infeasible. Verify the classification boundary and rejection behavior in P15. **READ** — `docs/spec.md:51-56,64,78-80`; `docs/patch_plan.md:45`.
- **TO READ FROM STANDARD (UK NA, BS EN 1993-1-1, BS EN 1993-1-5):** shear area and `eta`; shear-buckling criterion; patch-loading calculation and end-post rule; LTB constants; restraint, load-height and moment-gradient factors. Record each value/rule with its clause number in `docs/verification_record.md` before implementation. **READ** — `docs/spec.md:62-84`; `docs/patch_plan.md:45`.
- Implement bending, shear, bending-shear interaction, deflection, web bearing and LTB. Use the existing load and deflection rules unless explicitly fixed by A4; evaluate interaction at stations. **READ** — `docs/spec.md:37,62-84`.
- **ASSUMPTION — LTB section properties/model:** for flange-centroid spacing `h0=h-tf`, use Saint-Venant torsion constant `It=(2btf^3+hw*tw^3)/3` and warping constant `Iw=tf*b^3*h0^2/24`; derive elastic critical moment `Mcr` from the adopted code formulation using `E`, `G`, `Iy`, `Iz`, `It`, `Iw`, span, end restraints, load height and moment-gradient factor. Specify units and every boundary condition in P14. The thin-plate formulas and restraint/load factors require engineering confirmation. **READ** — `docs/spec.md:70,256`; `docs/patch_plan.md:45`; `docs/project_review.md:108-112`.
- **LTB evidence and decision:** `docs/spec.md:256` registers curve d for `2<h/b<=3.1`; interim rule: apply the special case only for strict `h/b<3.1`; designs with `h/b>=3.1` are rejected as outside the envelope and counted as invalid geometry. The checker compares integers (`10*h < 31*b`); P15/tests include the on-grid `h=620,b=200` exactly-3.1 case, plus `(610,200)` valid and `(630,200)` invalid. SCI AD 560 (7 Oct 2026) says welded I-sections with `h/b>3.1` use the general case, curve d, not the special case. The strict-grid count is 710,325; the old 710,820 figure (for `<=3.1`) is superseded. Restore `<=3.1` only by dated amendment before P16. **External engineering evidence:** [SCI AD 560](https://www.newsteelconstruction.com/wp/ad-560lateral-torsional-buckling-of-unrestrained-plate-girders/). UK NA text/applicability is not independently verified. **READ** — `docs/spec.md:256`; `docs/patch_plan.md:45`; `docs/project_review.md:108-112`.

## Common evaluation and metrics

- **Decision (project lead) — full primary population:** retain every context in each registered split in the primary population, including difficult contexts, contexts no method solves, and contexts later identified as infeasible. Never filter contexts based on method performance. S3 feasibility denominator is all contexts × seeds; abstentions and invalid top-1 designs count as failures. Report raw top-1, repaired/verified result (if repair is approved), abstentions, and their counts separately. **READ** — `docs/spec.md:142-144,150,177,250`; `docs/patch_plan.md:49-53`.
- **Decision (project lead) — gap denominators:** report gap only for feasible method outputs with a feasible reference, while always reporting the gap denominator and all-context feasibility alongside it. Report candidate/reference intersection gap separately from coverage; do not treat an infeasible output as zero gap or silently remove its context from feasibility. If the reference has no feasible output, mark reference failure and gap undefined; preserve the context in all-context feasibility and report it separately. Do not call such a context legitimately infeasible unless exhaustive enumeration or an independent infeasibility certificate establishes that fact. **READ** — `docs/spec.md:88-90,150,156-160,251`.
- **Decision (project lead):** S4 retains the registered one-sided upper 95% bound of median mass gap <=2 percentage points; calculate it on contexts where both the method and best-observed reference have feasible outputs, and publish that denominator plus full-population coverage/reference-failure counts. S3 and all primary feasibility summaries remain all-context. **READ** — `docs/spec.md:150,249-252`.
- **Decision (project lead) — tuning rule:** on every V context, compare raw feasibility over all V contexts; gap is the mean paired gap on contexts where both candidate and incumbent are feasible, with the intersection count shown. Preserve the existing rule: candidate feasibility cannot be lower and the intersection mean gap must improve by at least 0.5 percentage points. As intersection gap alone cannot reward feasibility gains, report both metrics and abstentions; no context is dropped from the primary feasibility denominator. **READ** — `docs/spec.md:138,379`; `docs/patch_plan.md:37`.

## P16 reference, envelope audit and cost

- **Decision (project lead):** use SLSQP, DE and CMA-ES on each context, with at most 1,000 unique checker calls per optimizer seed; run deterministic SLSQP once and DE/CMA-ES with seeds 0–9 fixed before P16. Construct the quality reference as the lightest feasible output observed across the prescribed seeds and methods; ties resolve by lower `h`, then lexicographic `(b,tw,tf)`. If none returns feasible, record reference failure and undefined gap; do not remove the context or assert infeasibility. This is a *best-observed* reference, never a proven global optimum. Publish each seed's success/abstention and calls. **READ** — `docs/spec.md:88-90,152,251-256`; `docs/patch_plan.md:45,49`.
- **Decision (project lead):** for S5, use the quality-winning optimizer's mean actual checker calls per single run over its fixed seeds (SLSQP's single deterministic run), never minimum-call or best-of-ten cost. Also report all-three-optimizers cost as the sum of per-method mean per-run calls. Separately report reference-construction cost: one SLSQP run plus DE and CMA-ES seeds 0–9. Report supplementary SLSQP call-equivalents alongside these costs; they do not replace primary S5 checker-call accounting. Charge training/tuning/pilot/label cost through `T`; `N*=T/(c_conv-c_learned)` only when the denominator is positive. **READ** — `docs/spec.md:152,252`; `docs/patch_plan.md:49`.
- **Decision (project lead): envelope audit** uses V only and no method results. Evaluate the maximum geometry `(h=900,b=450,tw=20,tf=40)` in each V context as one diagnostic point, not a feasibility certificate: depth caps, demand interactions and self-weight can make it infeasible and do not establish whether another geometry is feasible. Report such contexts as “maximum-corner failure,” not “unservable.” Report the Class 4 rejected share in the audit. A method-independent 2,000-geometry stratified grid panel is a secondary diagnostic; report feasible share by context group and best-in-panel designs, explicitly not global optima. Any proposed envelope change is made once, dated, before P16 baselines, then frozen. **READ** — `docs/spec.md:36-37,256,282-319`; `docs/patch_plan.md:45,49`.
- **Decision (project lead) — Stage 2 saturation:** assess on V against the best-observed reference only where that reference is feasible, while retaining all-context feasibility/reference-failure reporting. Exact match means relative mass difference <=0.5%. Report match, feasibility and gap separately. Do not infer no quality headroom from an infeasible reference or sampled panel. **READ** — `docs/spec.md:150,179,251`; `docs/patch_plan.md:49`; `docs/project_review.md:151`.
