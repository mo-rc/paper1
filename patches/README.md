# patches/

Optional records of substantial repository changes, kept as unified diff files (e.g. `git diff > patches/NNNN-name.patch`).

- They are reference material only: nothing applies them automatically, they are not part of any build or test run, and reproducibility never depends on them — the repository files themselves are the source of truth.
- The team normally edits the repository directly; a patch file is worth keeping only when a change is large and a standalone record of it is useful.
